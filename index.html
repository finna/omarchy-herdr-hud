Install once. Stay in the game.

Requires Omarchy Quattro, Herdr on your PATH, and Python 3.

omarchy plugin add https://github.com/finna/omarchy-herdr-hud.git --enable
Super H Toggle panelSuper Shift H Hide / show everythingCtrl Enter Send prompt

Add the optional keybindings using the setup instructions. This is a native desktop plugin; the browser illustration does not connect to your agents. Agent approvals are handled in Herdr. Tested on Omarchy Quattro 4.0.2 with a fullscreen terminal; individual games and multiple monitors are not yet verified.
